# Project Demo Videos

Place your Gemini-generated demo video files in this directory:

1. **FinSight Demo Video**:
   Save your video as: `finsight-demo.mp4`
   Path: `client/public/videos/finsight-demo.mp4`

2. **Factscope AI Demo Video**:
   Save your video as: `factscope-demo.mp4`
   Path: `client/public/videos/factscope-demo.mp4`

### Supported Formats:
- `.mp4` (H.264 video codec, AAC audio codec recommended for widest browser compatibility)
- `.webm`

### Git & Vercel:
When you commit and push these files to your GitHub repository, Vercel automatically deploys them as high-speed static assets with native browser streaming (byte-range seeking, mobile compatible, full controls).
